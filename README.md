# Olist 電商數據分析

以巴西 Olist 電商公開資料為基礎，從「銷售、顧客、賣家與物流」三個面向進行分析，
希望從交易資料中找出影響營收與營運表現的關鍵因素，並將分析結果整理成 Power BI 儀表板。

## 專案目標

這個專案不只想回答「賣了多少」，而是進一步從資料找出：

- 營收成長主要來自訂單增加，還是客單價提升？
- 哪些顧客具有較高價值與再次購買的潛力？
- 賣家的營收差異主要受到哪些因素影響？
- 不同地區的配送效率是否存在明顯差異？

從原始資料整理開始，使用 Python 進行資料清理與分析，
再透過 PostgreSQL / SQL 驗證分析結果，最後以 Power BI 將重要指標與洞察視覺化。

## 分析流程

**原始資料 → Python 資料清理 → 探索與商業分析 → PostgreSQL / SQL → Power BI 儀表板**

## 主要分析發現

### 銷售表現
- 完成約 **9.65 萬筆訂單**，商品營收約 **R$ 1,322 萬**
- 月營收與訂單量高度相關（**r ≈ 0.99**）
- 顯示營收成長主要來自「訂單量增加」，而不是客單價持續提高

### 顧客分析
- 約 **97% 為一次性購買顧客**，回購顧客僅約 3%
- 前 10% 高價值顧客貢獻約 **41.10% 營收**
- RFM 分群發現「近期高價值一次性顧客」具有值得關注的二次購買潛力

### 賣家與物流
- 賣家訂單量與營收呈明顯正相關（**r ≈ 0.80**）
- 約 **93.23%** 訂單能在預估日期前送達
- 不同地區仍存在配送時間與延遲率差異，可作為後續物流改善依據
